ABOUT THIS PROJECT

Small website. Useful learning.

This project is built with HTML and CSS. It demonstrates page navigation, responsive layouts, accessible checkboxes, and CSS-driven progress styling.

Habit completion is temporary and is not permanently saved. This version does not include accounts or a database.
