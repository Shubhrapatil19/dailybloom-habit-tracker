# DailyBloom

A responsive habit tracker with five pages and dark mode.

## Pages

- Home: daily habits and progress
- Tips: practical habit ideas
- Challenges: small activities with completion states
- Mood: temporary mood selection
- About: project information

## Technologies

HTML, CSS and JavaScript.

## Run locally

Open index.html in a browser or use VS Code Live Server.

## Features

- Responsive layouts
- CSS-based habit and challenge interactions
- Dark/light theme
- Theme preference saved in browser localStorage

Habit progress and mood selections are not permanently saved.
